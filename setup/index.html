Claim your mail server

This link carries the setup code for a freshly installed REST Mail server. With the app installed, opening it on your phone starts the setup. If you are reading this page instead, the app did not open: enter the code by hand.

Setup code

  1. Open REST Mail on your phone.
  2. Choose Set up a new server.
  3. Enter your server's address, then this code.

The code works once, and only until your server is claimed or restarted. Treat it like a password: whoever uses it first becomes the server's admin.

Setup links are made by a freshly installed REST Mail server, which prints one — with a QR code — every time it starts, until somebody claims it. Open the link on the phone where the app is installed.

Sign in to your new mail server

This link carries the sign-in for a freshly installed REST Mail server, from the QR code its installer showed. With the app installed, it opens the app with the sign-in filled in. If you are reading this page instead, the app did not open.

Open in the REST Mail app

Or sign in by hand: open REST Mail, choose Set up a new server, and enter these.

Server
(the one you installed)
Username
Password

Treat the password like any other: it lets whoever has it sign in as your server's admin. Signing in with it makes you choose your own and set up an authenticator, after which it stops working. It also stops working 72 hours after your server first took it.

This link carries a setup code, from a REST Mail server older than version 0.7. Nothing redeems setup codes any more: a server's first admin comes from the password its installer showed you. Sign in with that, in the app.
